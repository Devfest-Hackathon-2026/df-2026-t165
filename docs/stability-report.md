# デモ安定化の記録 — 2026年11月7日

## 修正したこと

1. **音声の停止**：終了・画面移動・ページ終了で音声接続とマイクを閉じる。マイク許可や接続が遅れて完了した場合も、後から開始しない。接続エラーやタイムアウトで資源を解放する。
2. **質問の取り違え**：未回答質問のボタンに個別の識別子を付け、先に届いた質問から引き継ぐ。同じ質問の二重登録を防ぎ、現在の質問をAIにも渡す。
3. **確認中の内容**：編集途中の値を元の下書きと分けて保存し、再読込後に復元する。確認前の編集を、確認済み知識として扱わない。
4. **修正の保持**：「未確認」に直した事実が、次の下書きで古い会話から復活しないようにする。追記した確認先の中に時刻が含まれていても、集合時間を勝手に上書きしない。
5. **体験用の回答**：晴れの日の質問に雨天用の場所を返さない。時間や確認先が欠けていれば、完了扱いにせず聞き返す。
6. **通信と保存**：処理中の画面切替で結果が別の記録に混ざるのを防止。不正な会話データや未対応の呼び出しを検証し、ローカルファイルを途中までの状態で書かないよう一時ファイルから置き換える。
7. **引き継ぎ**：Google公開後の接続チェック、3分の読み上げ台本、プッシュ時の自動ビルド・テスト設定例を追加。GitHub認証にworkflow権限がないため、設定例は `docs/check-workflow.yml` に置き、自動実行は未有効。

## 確認した範囲

- ローカルのビルド成功、自動テスト19件合格。
- うち音声の5件は模擬接続で、許可待ち・接続待ちのキャンセル、終了時の文字記録、接続失敗時の解放を検証。実機の音声認識や音声応答の試験ではない。
- ブラウザで架空の台詞→下書き→場所を未確認に修正→再読込→確認保存→再び下書き、という流れを確認。修正値が残り、古い場所が復活しなかった。
- 未回答質問を2件入力し、それぞれ登録。最初の質問から聞き取りが始まることを確認。
- 接続チェック用スクリプトはローカルの体験モードで実行して確認。Google版の実接続は未検証。

## 未完了のこと

- 語り手や担い手を対象とした実測はまだない。今回の操作確認から利用者評価の数値は作っていない。
